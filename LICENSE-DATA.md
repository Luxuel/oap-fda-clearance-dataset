# Data status and code licence

openFDA and AccessGUDID are US public-domain government data sources. This package contains frozen extracts of their public device records, including submitted company and brand names. No new licence is imposed on those source data by this package.

The openFDA snapshot metadata identifies `https://open.fda.gov/license/` and `https://open.fda.gov/terms/`. AccessGUDID source: `https://accessgudid.nlm.nih.gov/`. These source references were not refetched during preparation.

Code licence: the script and tests (`code/`, `tests/`) are released under the MIT License; see `LICENSE`.
